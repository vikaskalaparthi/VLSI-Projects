# VLSI-Projects

These projects were done by me in the VLSI Design course.

CMOS Inverter – delay, static power, dynamic power, NML & NMH for different voltage, width, length, process corners, and temperature. 

CMOS Inverter – VTCs for different \(I_{on,pMOS}/I_{on,nMOS}\) ratios with NML, NMH, delay, rise time, fall time, static power, and dynamic energy.

Five-Stage Ring Oscillator – frequency at different process corners and temperatures.

Static CMOS Logic – NAND2, NOR2, XNOR2, and given logic functions with equal rise/fall delay, truth tables, dynamic energy, and delay.

4-bit Ripple Carry Adder – CMOS Gates and Mirror Adder with comparison of dynamic energy and Sum/Carry delay.

6T-SRAM and Inverter Layout
