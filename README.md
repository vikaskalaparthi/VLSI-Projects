# VLSI-Projects

1. These projects were done by me in the VLSI Design course.
2. CMOS Inverter – delay, static power, dynamic power, NML & NMH for different voltage, width, length, process corners, and temperature. 
3. CMOS Inverter – VTCs for different (I{on,pMOS}/I{on,nMOS}) ratios with NML, NMH, delay, rise and fall time, static power and dynamic energy.
4. Five-Stage Ring Oscillator – frequency at different process corners and temperatures.
5. Static CMOS Logic – NAND2, NOR2, XNOR2, and given logic functions with equal rise/fall delay, truth tables, dynamic energy, and delay.
6. 4-bit Ripple Carry Adder – CMOS Gates and Mirror Adder with comparison of dynamic energy and Sum/Carry delay.
7. 6T-SRAM and Inverter Layout.
